# Fix Report 06 — 節約・無駄遣いなし・間食なし機能のUI導線追加

## ブランチ
`feat/savings-action-ui`

## 対応した問題

store に `addSavingsRecord`, `recordNoWasteDay`, `recordSnackFreeDay` が存在していたが、
画面側から呼び出されておらず、ユーザーが連続記録を増やす導線がなかった。

## 修正内容

### `mobile/app/(tabs)/index.tsx`

「今日のアクション」カードに3つのボタンを追加（2列目の横並び）：

| ボタン | アクション | 押した後の状態 |
|--------|---------|-------------|
| 💰 節約を記録 | `addSavingsRecord(amount)` | 今日記録済みなら「記録済み」に変化 |
| ✨ 無駄遣いなし | `recordNoWasteDay()` | 今日記録済みなら「記録済み！」に変化 |
| 🥗 間食なし | `recordSnackFreeDay()` | 今日記録済みなら「記録済み！」に変化 |

- 「節約を記録」ボタンは金額入力モーダルを開く
- 「無駄遣いなし」「間食なし」は1タップで記録、重複記録は防止
- 各ボタンにはストリーク日数または今日の状態を表示

**節約入力モーダル:**
- 金額入力（`/^\d+$/` + `isSafeInteger` バリデーション）
- キャンセル / 記録するボタン
- `¥10 = 1pt` の説明テキストを表示

## 実機で確認すべき点

| # | 確認操作 | 期待結果 |
|---|---------|---------|
| 1 | ホーム画面を開く | 今日のアクションに「節約を記録」「無駄遣いなし」「間食なし」ボタンが表示される |
| 2 | 「無駄遣いなし」をタップ | ボタンが緑色の「記録済み！」に変化、再タップしても変わらない |

| 6 | 節約モーダルで「abc」と入力して「記録する」 | エラーアラートが表示される |
| 7 | 翌日にアプリを開く | 「無駄遣いなし」「間食なし」が未記録状態に戻る |
| 8 | ミッション画面で「節約成功」ミッションを確認 | 節約記録後に進捗が更新されている |
