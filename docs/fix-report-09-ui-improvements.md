# Fix Report 09 — バッジ・ミッション・統計・ホームのUI改善

## ブランチ
`feat/ui-improvements`

## 対応した問題（監査番号 #11, #12, #17, #18, #19, #21, #22, #23, #24）

複数のUI/UX課題を一括修正。

## 修正内容

### `mobile/app/(tabs)/missions.tsx`

- 「毎日 24:00 にリセット」→「次回起動時に更新」に変更（実装と文言を一致させた）

### `mobile/app/(tabs)/badges.tsx`

**進捗バーと残り回数の追加（#22）:**
- 未獲得バッジカードに進捗バー（現在値 / 目標値）を追加
- 「あと X 回/円」のテキストを表示
- バッジ種別ごとに適切な現在値を計算（自炊回数、節約額、レベル、ストリークなど）

**「次の達成まで」ヘッダーの修正（#22）:**
- 未獲得バッジ数ではなく「最も達成に近いバッジ名」を表示

**フッター文言の修正（#23）:**
- 「達成するたびにポイントをGET!」→「バッジを集めて、もっと節約上手になろう！」に変更
- store 側にバッジ獲得ポイント付与がないため、誤解を招く文言を削除

### `mobile/app/(tabs)/stats.tsx`

**未来月移動を無効化（#21）:**
- 現在月以降の「＞」ボタンを `disabled`（グレーアウト）に変更

**統計サマリーのレイアウト変更（#19）:**
- Before: 3カラム横並び（食費合計・自炊回数・予算使用率）
- After: 1段目に「食費合計」大きく表示、2段目に「自炊回数 + 予算使用率」2列

**円グラフ凡例を全件表示（#11）:**
- `slice(0, 4)` を削除 → 全カテゴリの凡例を表示

**支出記録の「もっと見る」ボタン（#12）:**
- `slice(0, 8)` を廃止し、9件以上ある場合に「もっと見る（残り X 件）」ボタンを追加
- 展開後は「折りたたむ」ボタンで戻れる

### `mobile/app/(tabs)/index.tsx`

**ホーム見出し変更（#18）:**
- 「今月の予算」→「今月の使用状況」に変更

**食費合計行の強調（#17）:**
- 「食費合計」バー行に薄い緑背景・太字・枠線を追加してスーパー予算・お小遣いと区別
