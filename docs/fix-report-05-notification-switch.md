# Fix Report 05 — 通知スイッチの整理

## ブランチ
`fix/notification-switch`

## 対応した問題

設定画面の「デイリー通知」「ミッション通知」スイッチが local state の切り替えだけで、
AsyncStorage への保存も実際の通知送信もなかった。
ユーザーには通知が有効になったように見えるため、期待と実動作がズレていた。

## 修正内容

### `mobile/app/(tabs)/settings.tsx`

- `dailyNotif` / `missionNotif` の `useState` を削除
- `Switch` のインポートを削除
- スイッチを「近日対応予定」バッジに変更

**Before:** 操作できる Switch（見た目のみ）  
**After:** 黄色の「近日対応予定」バッジ（無効状態を明示）

通知機能が実装されたタイミングで、このバッジを実際の Switch + AsyncStorage + expo-notifications に差し替える予定。

## 実機で確認すべき点

| # | 確認操作 | 期待結果 |
|---|---------|---------|
| 1 | 設定画面を開く | 通知セクションにスイッチではなく「近日対応予定」バッジが表示される |
| 2 | デイリー通知・ミッション通知の行を確認 | 無効（タップ不可）の状態で表示される |
| 3 | 画面全体のレイアウトを確認 | 他のセクション（予算設定・データ管理）が正常に表示される |
