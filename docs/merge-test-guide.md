# マージ後 動作確認ガイド

今回 main にマージしたブランチと、それぞれの確認ポイントをまとめています。

---

## 共通の事前準備

```bash
cd mobile
npm run start       # Expo 開発サーバー起動
```

Android / iOS シミュレーター（またはデバイス）でアプリを起動する。

---

## 1. fix/cooking-modal-date-validation — 自炊記録モーダルの日付バリデーション

**確認画面:** ホームタブ → 自炊記録モーダル

| 手順 | 期待結果 |
|---|---|
| ① ホームの「自炊記録」ボタンをタップ | モーダルが開く |
| ② 日付フィールドが今日の日付で初期化されていること | 空欄でない |
| ③ 支出金額に文字や負の値を入力して「保存」 | エラーメッセージが表示される |
| ④ 有効な金額（例: 500）を入力して保存 | 記録が追加されホームに反映される |

## 2. fix/mission-reset-init — ミッション初期化の stale closure 修正

**確認画面:** ミッションタブ

| 手順 | 期待結果 |
|---|---|
| ① アプリを起動する | デイリーミッション3件・ウィークリーミッション3件が表示される |
| ② 日付を変えてアプリを再起動（デバイスの日付を1日進める） | デイリーミッションがリセットされ、新しいミッションが生成される |
| ③ 週をまたいだ場合 | ウィークリーミッションもリセットされる |

## 3. fix/mission-state-immutable — ミッション state のイミュータブル更新

**確認画面:** ミッションタブ → 支出・自炊記録後

| 手順 | 期待結果 |
|---|---|
| ① ホームで支出を記録する | ミッションタブで「記録の習慣」の進捗が増える |
| ② 自炊を記録する | 「自炊チャレンジ」の進捗が増える |
| ③ ミッション達成後に「受け取る」ボタンをタップ | ポイントが加算され、ミッションが完了済み表示になる |
| ④ 同じミッションを再度受け取れないこと | ボタンが非活性または非表示になる |

**確認画面:** バッジタブ

## 7. feat/savings-action-ui — 節約・無駄遣いなし・間食なし UI 導線

**確認画面:** ホームタブ → アクションボタン群

| 手順 | 期待結果 |
|---|---|
| ① ホームに「節約を記録」ボタンが表示されている | 表示確認 |
| ② 「節約を記録」をタップ → モーダルで金額を入力して保存 | 節約記録が追加され、ポイントが加算される |
| ③ 「無駄遣いなし」をタップ | 当日の無駄遣いなし記録が登録される（2回目タップは無効） |
| ④ 「間食なし」をタップ | 当日の間食なし記録が登録される（2回目タップは無効） |
| ⑤ 不正な金額（文字・0・負値）で節約を保存しようとする | エラーアラートが表示され保存されない |
