# UI Tone and Color Palette: Refined Pop

## Direction

「節約マスター」は、食費管理の堅実さと、ミッション・ポイント・ガチャによる継続の楽しさを両立するアプリです。新しいUIでは、可愛らしさに寄せすぎず、金融アプリの信頼感を土台にしながら、報酬や行動導線にはキャッチーな明るさを加えます。

目指す印象:

- 上質: ネイビー、アイボリー、深いグリーンで落ち着いた土台を作る
- ポップ: コーラル、ミント、マスタードを小面積で使い、行動したくなる軽さを出す
- ゲーム感: レベル、ポイント、ミッション、ガチャは報酬感を強める
- 日本向け: 金額、日次記録、食費カテゴリが直感的に読める実用的な画面にする

比率の目安:

- 信頼感・上質感: 65%
- ポップさ・楽しさ: 35%

避ける印象:

- 子ども向けのかわいさ
- 全面パステル、全面ビビッド
- 紫グラデーション中心の既視感
- ゲーム演出が強すぎて家計簿として読みにくい状態

## Typography

和文の可読性を優先しつつ、少し親しみやすい印象にします。丸すぎるフォントは避け、画面全体はすっきり見せます。

```css
font-family:
  "Noto Sans JP",
  "Inter",
  "Hiragino Kaku Gothic ProN",
  "Yu Gothic",
  system-ui,
  sans-serif;
```

使い分け:

- ヘッダー: `700`、詰めすぎない
- セクション見出し: `700`
- 本文: `400` から `500`
- 金額・ポイント: `700`、数字が主役になるサイズ
- バッジ・チップ: `600`、短く読みやすく

## Shape and Motion

- カード角丸: `12px`
- 小ボタン・チップ: `999px` のピル形状も許容
- 入力カード・統計カード: `10px` から `12px`
- 報酬・ガチャ・達成演出: `16px` まで許容
- 影は軽く、ポップ要素だけ少し浮かせる
- アニメーションは短く、押したときの反応や達成時のみに限定する

## Component Tone

### Header

ヘッダーは `Midnight Navy` で締め、レベルとポイントに `Champagne Gold` を使います。高級感を残しつつ、ステータスがすぐ見える構成にします。

### Home Dashboard

ホームは最もポップにしてよい画面です。

- 今日の食費、残り予算、ポイントを上部に集約
- 「記録する」導線はコーラルまたはフォレストで明確に
- カテゴリ入力はアイコン付きで明るくする
- 達成・自炊・ミッションはミントとゴールドで報酬感を出す

### Stats

統計は落ち着かせます。アクセントはグラフと改善値だけにし、読みやすさを優先します。

### Missions

ミッションはポップ寄りにします。進捗バー、報酬チップ、完了チェックで「進んでいる感」を見せます。

### Badges and Collection

バッジとガチャは最も報酬感を出します。ただし、全面金色ではなく、カードやメダルの小面積に限定します。

### Settings

設定は最も落ち着いた画面にします。色はネイビー、アイボリー、グリーン中心で、危険操作のみ赤を使います。

## Migration Notes

1. 背景を紫グラデーションから `Warm Ivory` に変更する
2. ヘッダーを `Midnight Navy` に変更し、ポイントとレベルにゴールドを使う
3. カテゴリカードは白地 + カラーアイコン + 細い境界線にする
4. ミッションとガチャだけポップアクセントを強める
5. 統計と設定は色数を抑え、情報の読みやすさを優先する
6. 角丸は `12px` を基準にし、報酬系だけ少し丸くする
