# Fix Report 07 — 統計の日別推移グラフを横スクロール棒グラフに変更

## ブランチ
`fix/stats-chart-timeline`

## 対応した問題

`LineChart` は渡された点を等間隔に描画するため、
5/1、5/20、5/31 が同じ間隔で表示され、実際の日付間隔と乖離していた。
また支出がない日はグラフに含まれず、日付の読み取りが難しかった。

## 修正内容

### `mobile/app/(tabs)/stats.tsx`

- `LineChart` の import を削除
- `getChartDataWithRecordedDays`（点を間引く関数）を削除
- 「日別推移」カードを **横スクロール棒グラフ** に置き換え

**棒グラフの仕様:**
- 月の全日付（1〜末日）を等幅（14px）で横並び
- 各日の棒高さ = 当日支出 / 月最大支出 × 80px
- 支出がない日は棒なし（高さ0）
- 支出が月最大の80%超のバーは赤（#F44336）で警告表示
- 日付ラベル（日番号）を棒の下に表示
- `ScrollView horizontal` で月末日まで横スクロール可能

## 実機で確認すべき点

| # | 確認操作 | 期待結果 |
|---|---------|---------|
| 1 | 数日分の支出を記録して統計画面を開く | 支出した日だけ棒が立ち、金額に比例した高さになる |
| 2 | 棒グラフを左右にスワイプ | 月末まで全日付がスクロールできる |
| 3 | 支出がない日 | 棒は表示されず、日付ラベルのみ表示される |
| 4 | 月の最大支出日 | 棒が最も高い（80px）か、赤色で表示される |
| 5 | 月に支出が0件の場合 | 「まだ記録がありません」のテキストが表示される |
