# コミット・PR作成スキル

変更のコミットからPR作成までを行う。

## ワークフロー

### 1. 変更内容の確認

```bash
git status
git diff --stat
```

変更内容をユーザーに表示し、コミット対象を確認する。

### 2. コミット作成

```bash
git add <変更ファイル>
git commit -m "<コミットメッセージ>"
```

#### コミットメッセージ形式

```
feat: <変更内容の要約> (#<イシュー番号>)

- <変更点1>
- <変更点2>
- <変更点3>

Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>
```

### 3. プッシュ

```bash
git push -u origin <ブランチ名>
```

### 4. PR作成

**PRは日本語で作成する。**

```bash
gh pr create --title "<タイトル>" --body "$(cat <<'EOF'
## 概要
- <変更内容の要約>

## 変更内容
- <変更点1>
- <変更点2>
- <変更点3>

## テスト計画
- [ ] テスト項目1
- [ ] テスト項目2

Closes #<イシュー番号>
EOF
)"
```

PR作成後、PRのURLをユーザーに表示する。
