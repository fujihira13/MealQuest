# App Store / Play Store Asset Requirements

## iOS App Store

### Screenshots

| Device | Resolution | Required | Notes |
|--------|-----------|----------|-------|
| iPhone 6.7" (15 Pro Max, 16 Plus etc.) | 1290×2796 or 1320×2868 | **Required** | Min 2, max 10 |
| iPhone 6.5" (14 Plus, 13 Pro Max etc.) | 1242×2688 or 1284×2778 | Optional | Replaced by 6.7" |
| iPad Pro 12.9" (6th gen) | 2048×2732 | **Required if supportsTablet: true** | Min 2, max 10 |
| iPad Pro 11" | 1668×2388 | Optional | Replaced by 12.9" |

- Portrait orientation required for portrait-only apps
- Must show actual app UI (no device frames required but allowed)
- Safe zone: keep important content away from corners/notch

### Other iOS Assets

| Asset | Size | Required |
|-------|------|----------|
| App Icon | 1024×1024px PNG, no alpha | ✅ Yes (via app.json `icon`) |
| Splash / Launch Screen | Configured via expo-splash-screen plugin | ✅ Yes |

---

## Android Play Store

### Screenshots

| Device | Resolution | Required | Notes |
|--------|-----------|----------|-------|
| Phone | Min 320px short side, max 3840px long side | **Required** | Min 2, max 8 |
| Tablet 7" | Same constraints | Optional | |
| Tablet 10" | Same constraints | Optional | |

Recommended phone screenshot size: **1080×1920px** (9:16 portrait)

### Feature Graphic

| Asset | Size | Required | Notes |
|-------|------|----------|-------|
| Feature Graphic | **1024×500px** | ✅ **Yes** | Shown at top of Play Store listing |

- JPEG or 24-bit PNG (no alpha)
- Displayed as banner in store listing — must look good without the icon overlaid
- Keep text/logo in the center 80% (safe zone)

### Other Android Assets

| Asset | Size | Required |
|-------|------|----------|
| App Icon | 512×512px | ✅ Yes (auto-generated by EAS from `icon.png`) |
| Adaptive Icon Foreground | 1024×1024px, transparent bg | ✅ Yes |
| Adaptive Icon Background | 1024×1024px solid color | ✅ Yes |

---

## Expo app.json Checklist

```jsonc
{
  "expo": {
    "icon": "./assets/images/icon.png",          // 1024×1024 PNG
    "ios": {
      "supportsTablet": false,                   // true → iPad screenshots required
      "buildNumber": "1"                         // increment each submission
    },
    "android": {
      "versionCode": 1,                          // increment each submission
      "adaptiveIcon": {
        "foregroundImage": "...",
        "backgroundImage": "...",                // or use backgroundColor
        "monochromeImage": "..."                 // optional but recommended
      }
    },
    "plugins": [
      ["expo-splash-screen", {
        "image": "./assets/images/splash-icon.png",
        "imageWidth": 200,
        "resizeMode": "contain",
        "backgroundColor": "#ffffff"
      }]
    ]
  }
}
```
