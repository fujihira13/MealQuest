# レイアウト仕様詳細

## ゾーニング（1080×1920）

| ゾーン | 位置 | 内容 |
|--------|------|------|
| ヘッダー | 0-10% (0-192px) | プログレスドット (top:80px) |
| 見出し | 10-20% (192-384px) | シーンタイトル + アクセントライン |
| 余白 | 20-30% (384-576px) | 空き（呼吸の余白） |
| コンテンツ | 30-75% (576-1440px) | コードウィンドウ + 解説カード |
| 空き | 80-100% (1536-1920px) | 何も置かない（スマホUI回避） |

## パターンA: 比較型の追加仕様

コードウィンドウ内を上下に分割:
- 上半分: `rgba(239,68,68,0.06)` 微赤背景 + 「// ❌ 悪い例」ヘッダー
- 下半分: `rgba(16,185,129,0.06)` 微緑背景 + 「// ✅ 良い例」ヘッダー
- 区切り線: `rgba(255,255,255,0.1)` height 2px
- 各セクション padding: 16px 20px

## パターンB: コード単体型の追加仕様

- 行番号表示（左側、色: #484f58、幅40px、右マージン16px）
- 自動シンタックスハイライト用tokenize関数を使用
- コード fontSize: 28-30

## パターンC: ターミナル型の追加仕様

- プロンプト構成: `akira@mac`(緑) ` `(白) `~`(青) ` % `(白)
- コマンド行: タイプライター表示
- 出力行: フェードインで段階表示（opacity 0→1）
- 成功行: ✅ 緑色
- ビルドステップ: => 黄色
- ターミナル内 fontSize: 22

## シーン構成の目安

| 尺 | シーン数 | 構成 |
|----|---------|------|
| 15秒 | 3 | タイトル(3s) + メイン2個(5s each) + まとめ(2s) |
| 30秒 | 4 | タイトル(3s) + メイン3個(7s each) + まとめ(6s) |
| 45秒 | 5 | タイトル(5s) + メイン3個(10s each) + まとめ(10s) |
| 60秒 | 5-6 | タイトル(5s) + メイン4個(10s each) + まとめ(15s) |

## フォント

- コード: `'JetBrains Mono', 'Fira Code', 'SF Mono', Menlo, monospace`
- ターミナル: `'SF Mono', Menlo, monospace`
